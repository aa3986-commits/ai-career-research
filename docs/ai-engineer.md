# AI Engineer

## What does this person do?

An AI Engineer creates applications using AI models. Examples include chatbots, document search, and automation tools.

## Typical responsibilities

- Build AI features for applications.
- Connect to AI services through APIs.
- Prepare data and test answers.
- Improve accuracy, reliability, and safety.
- Monitor performance and costs.

## Useful skills

Python, JavaScript, APIs, large language models, retrieval-augmented generation (RAG), testing, and cloud deployment.

## Portfolio project

Build a document question-answering app that displays the source used for each answer.
