# My Student-to-AI Career Roadmap

A practical plan for someone studying Business and Information Systems. This is a suggested learning path, not a promise of employment.

## Stage 1 — Understand the industry

**Goal:** Learn the difference between AI Engineer, Forward Deployed Engineer, Machine Learning Engineer, and AI Product Manager.

- Read two real job descriptions for each role.
- Write down skills that appear repeatedly.
- Pick one career to explore more deeply.

**Evidence:** A career comparison table with job links.

## Stage 2 — Learn the tools

**Goal:** Become comfortable building and explaining simple projects.

- Practice Git and GitHub.
- Learn basic Python and APIs.
- Practice SQL and working with data.
- Learn how AI systems can make mistakes.

**Evidence:** Small GitHub projects with clear READMEs.

## Stage 3 — Build a portfolio case study

**Project idea: Retail FAQ Assistant**

Create a small assistant that answers questions about sample store policies and products. Use made-up or public information, not private customer data.

Document:

1. Who would use the tool?
2. What problem does it solve?
3. How does the prototype work?
4. What tests did I run?
5. What mistakes did I find?
6. What would I improve?

**Evidence:** Demo, screenshots, test examples, and a reflection.

## Stage 4 — Prepare for interviews

- Explain my project in simple words.
- Practice describing a problem and solution.
- Be ready to talk about teamwork and customer needs.
- Compare my skills with current job requirements.

## My first next step

I will choose **one job posting** from the [sources page](/resources), identify three skills it requests, and plan a project that demonstrates at least one of those skills.
