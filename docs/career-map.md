# The AI Career Map

Not every AI job is about training a model. Some people build applications, some work directly with customers, and others decide what should be built.

## Compare the four paths

| Career | Main question | Common work | Best portfolio evidence |
| --- | --- | --- | --- |
| Forward Deployed Engineer | How can we solve this customer's problem? | Customer meetings, coding, integrations | Working prototype and customer story |
| AI Engineer | How can we build this AI feature? | APIs, application code, evaluations | AI app with tests |
| Machine Learning Engineer | How can we make a model work reliably? | Data, training, deployment | Model experiment and results |
| AI Product Manager | Should we build this, and for whom? | User research, requirements, planning | Product brief and prototype |

## A day at work: same problem, different jobs

Imagine a retail store wants an AI assistant that helps employees find product information.

**Forward Deployed Engineer:** Meets the store team, learns how employees work, and connects the assistant to the store's systems.

**AI Engineer:** Builds the assistant interface and connects it to an AI model.

**Machine Learning Engineer:** Helps evaluate model quality and improve the system using data.

**AI Product Manager:** Decides which employee problems to solve first and how to measure success.

## Which path matches my interests?

- If I like **people + coding**, I can explore Forward Deployed Engineering.
- If I like **building apps**, I can explore AI Engineering.
- If I like **data + mathematics**, I can explore Machine Learning Engineering.
- If I like **business + product decisions**, I can explore AI Product Management.

These are broad comparisons. Real job requirements differ between companies. Check the [job research sources](/resources).
