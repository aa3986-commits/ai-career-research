# Forward Deployed Engineer (FDE)

## What does this person do?

A Forward Deployed Engineer works with customers to understand business problems and build useful technical solutions. Some roles involve AI software and data integrations.

## Typical responsibilities

- Meet customers and understand their needs.
- Build software prototypes and working tools.
- Connect AI tools with business data.
- Test solutions and fix problems.
- Explain technical ideas to nontechnical people.

## Useful skills

Python or TypeScript, APIs, databases, cloud tools, AI evaluation, communication, and problem-solving.

## Portfolio project

Build an AI assistant that answers sample retail-store questions. Show test questions, results, and how you handle incorrect answers.
