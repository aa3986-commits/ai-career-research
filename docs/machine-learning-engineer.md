# Machine Learning Engineer

## What does this person do?

A Machine Learning Engineer builds and maintains software that learns patterns from data.

## Typical responsibilities

- Clean and prepare datasets.
- Train and evaluate models.
- Write reliable software.
- Deploy models to applications.
- Monitor accuracy and performance.

## Useful skills

Python, SQL, statistics, scikit-learn, PyTorch or TensorFlow, data pipelines, and cloud services.

## Portfolio project

Train a simple product-demand prediction model using an open dataset. Explain the results and limitations.
